# SZL F-Series to E-Series Steering Retrofit Workflow

## Goal

Generate conservative local daten patch bundles for SZL, KOMBI, and EGS that can be reviewed before use.

## Recommended order

1. Read and save original SZL trace.
2. Read and save original KOMBI trace.
3. If paddles are involved, read and save original EGS trace.
4. In the app, open the Steering screen.
5. Pick a retrofit bundle.
6. Load SZL template first and review each changed parameter.
7. Load KOMBI template and review MFL-related flags.
8. For paddle retrofits, load the EGS template and review paddle-related flags.
9. Use the validation checklist before any live write attempt outside the app.
